# ux-03: 共通ナビゲーションバー

## 概要
全画面共通のナビゲーションバーを実装する。

## 目的
- ユーザーがどこからでも主要画面に1タップで遷移できる
- アプリのブランド・トーンを共通化する

## タスク
- `app/src/components/Navigation.tsx` を作成
- 下部固定タブバー(モバイル前提)で以下を配置:
  - ホーム
  - 偏愛登録 (+)
  - 交換 (QR)
  - プロフィール
- アクティブタブのハイライト
- `App.tsx` のレイアウト枠に組み込み(認証済み画面のみ表示)

## 完了条件
- 各タブから対応画面に遷移できる
- 現在地が視覚的にわかる
