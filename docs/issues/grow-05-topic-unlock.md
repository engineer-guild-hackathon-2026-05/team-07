# grow-05: 話題解放システム

## 概要
育成レベルが一定値に達するごとに新しい話題(`unlockedTopics`)を解放する仕組みを実装する。

## 目的
- ユーザーが目標を持って育成を続けられるようにする
- 一度に全情報を開示せず、段階的に偏愛を理解させる体験を作る

## タスク
- キャラ生成時 ([char-04](./char-04-egg-generation.md)) に「将来解放しうる話題候補リスト」を `characters` ドキュメントに保持(例: 10件)
- `growthLevel` が閾値を超えるたびに `unlockedTopics` に1件移動
- 育成画面に「次の話題まで残り○○」のヒント表示
- 解放済みトピックの一覧UIをキャラ画面に追加
- 解放したトピックは `grow-03` の system prompt にも追加し、会話の幅を広げる

## 完了条件
- レベルアップでトピックが1つ解放され、画面に表示される
- 全解放後はその旨が表示される
