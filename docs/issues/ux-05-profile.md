# ux-05: プロフィール画面

## 概要
自分のプロフィール・偏愛一覧・交換履歴・育成キャラ一覧を表示する。

## 目的
- ユーザーが自分の活動を振り返れる場所を提供する
- 設定・ログアウトの導線も兼ねる

## タスク
- `app/src/pages/Profile.tsx` を実装
- 表示要素:
  - ユーザー名、アイコン、登録日
  - 自分が登録した偏愛一覧
  - 交換履歴 ([exch-04](./exch-04-exchange-history.md))
  - 育成済み/育成中キャラクター一覧
  - ログアウトボタン
- (任意) ユーザー名・アイコンの編集モーダル
- タブ or アコーディオンで切り替え

## 完了条件
- 自分のデータが正しく一覧表示される
- ログアウトでログイン画面に戻る
